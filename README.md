# Prva Android aplikacija

Prva aplikacija, ki sem jo izdelal v Android Studiu pri predmetu Razvoj mobilnih aplikacij.

Namen naloge je bil spoznati osnovno strukturo Android projekta, delo z uporabniškim vmesnikom in dodajanje preprostih funkcionalnosti.

## Funkcionalnosti

Aplikacija vsebuje:
- TextView elemente
- Button
- CheckBox
- RadioButton
- Floating Action Button
- Toast sporočilo ob kliku na gumb
- Snackbar ob kliku na Floating Action Button
- postavitev elementov s ConstraintLayout

Besedila aplikacije so shranjena v `strings.xml`.

## Uporabljeno

- Android Studio
- Java
- XML
- Gradle

## Struktura projekta

Glavne datoteke:

- `MainActivity.java` - glavna logika aplikacije
- `activity_main.xml` - uporabniški vmesnik
- `strings.xml` - besedila uporabljena v aplikaciji
- `AndroidManifest.xml` - osnovne nastavitve aplikacije

## Zagon

Projekt se lahko odpre v Android Studiu in zažene na Android emulatorju ali fizični Android napravi.
